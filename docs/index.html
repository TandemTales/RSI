    R01 / LIVE DEBUG

    v1

    Instruction reference
    move x y
    Walk to a tile, horizontal first. Walls and robots block movement. Coordinates start at (0, 0) in the upper left.
    pick N|E|S|W
    Take one adjacent part. One part fits in each robot.
    drop N|E|S|W
    Deliver to the assembler, return to the bin, or leave a part on the floor.
    activate N|E|S|W
    Spend 3 buffered parts to build a robot in 6 ticks. A busy or under-supplied machine lets the route continue.
    repeat
    Restart from line 1. Required as the last command. All other failed actions wait and retry.
    02 / BREAK SOMETHING

    More robots. Same floor.

    Two robots cannot share a tile or swap places. Opposing routes can deadlock. Try the jam, inspect the blocked line, then route one robot around the other.
